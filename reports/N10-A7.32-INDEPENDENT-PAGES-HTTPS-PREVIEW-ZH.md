## 三、锁定预览的安全架构（不能误当真实登录站）

锁定版 `_headers` 与上一阶段“未来真实认证页面”模板不同：
- `Content-Security-Policy`：`default-src 'none'`、`frame-ancestors 'none'`、`base-uri 'none'`、`form-action 'none'`、`object-src 'none'`、`worker-src 'none'`、`connect-src 'none'`、`frame-src 'none'`、`script-src 'self'`、`style-src 'self'`、`img-src 'self' data:`、`font-src 'none'`、`upgrade-insecure-requests`。
- 显式**禁止所有外部连接**，包括 Supabase、Cloudflare Turnstile、生产服务或任何未知源。锁定预览脚本也不使用 `fetch()` 或 `createClient()`。
- HTTP 级 `X-Frame-Options: DENY`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`Cache-Control: no-store, private, max-age=0`、`Cross-Origin-Opener-Policy: same-origin`、`Strict-Transport-Security: max-age=31536000`、浏览器权限禁用与 `X-Robots-Tag: noindex, nofollow, noarchive`。

- 账号和密码输入控件全部 disabled；真实验收按钮 disabled。无需真实用户名、密码、Google OAuth、Turnstile 或 JWT。
- **不要**把这套 `connect-src 'none'` 响应头直接作为将来已批准的真实认证 CSP；届时会另外根据固定 Staging API 与 Turnstile 所需来源建立、验证、审查并部署安全策略。
- 静态 Pages 构建在 CI 中生成；本轮不把任何 CI 临时启用的认证 SDK 或 CAPTCHA bundle 纳入产物。
