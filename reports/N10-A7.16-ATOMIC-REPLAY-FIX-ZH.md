# MMHVAULT · N10-A7.16 Turnstile 单次使用修复

日期：2026-10-28 UTC。此阶段仅修改独立 Staging 测试函数与 Auth-QA 页面。

## 真实故障证据
用户使用已有 QA 账号和真实 Cloudflare Turnstile 测试，首次正确动作返回 HTTP 200 / siteverify_pass，但第二次提交同一令牌仍返回 HTTP 200 / siteverify_pass。错误动作测试此前正常拒绝。Cloudflare 文档规定令牌只能验证一次，因此不能将该重放场景视为通过。

## 修复内容
- 新函数 `mmh-n10a15-siteverify-qa` v2 保持 `verify_jwt=true`、既有 QA 用户 RLS、每账户每小时最多 6 次、固定 2026-10-30 17:00 UTC 过期。
- 新增 HMAC(token) 对应的 PostgreSQL 原子单次使用桶：限额 1 次、时长 600 秒；在调用 Cloudflare 之前占用，失败即拒绝。跨 Edge 实例共享，避免仅用内存标记造成并发绕过。
- 响应码 `403 / token_replayed` 明确代表 Staging 应用层防重放，而非声称 Cloudflare 第二次自身拒绝。
- 页面 `n10a715-real-siteverify-qa.html` 已更新为识别这一响应，结果文案明确区分上游验证与应用层保护。
- 不保存原始验证码、密码、JWT 或用户邮箱到 QA 报告。

## 尚未验收
需要账号持有人使用更新后的 QA 页面生成**新一次性验证码**，首次应显示服务器 Siteverify 200，第二次应显示服务器原子防重放 403/token_replayed。勿发送密码或令牌；限流每小时最多 6 次，若出现 429 请勿重复点击。

**正式三登录发布继续 BLOCKED。** 测试函数并不会自动删除，过期后需要安全清理。
