## 二、安全设计边界

此页面是**纯 UI + 纯客户端模拟**，不是实际三登录服务：
- CSP 中 `connect-src 'none'`、`form-action 'none'`、`frame-src 'none'`、`object-src 'none'`；不包含远程 JS/CSS、网络 `fetch`、`XMLHttpRequest`、Supabase SDK、Google OAuth、JWT、Cookie API、localStorage/sessionStorage。
- 页面只在内存中短暂处理用户填写的**示例用户名/邮箱**，不保存、发送或记录密码；模拟提交后清空密码输入框。
- 不修改正式 GitHub `myintmoehein0115024/MMHVAULT`、生产 Supabase `vrypucmyrztxgiqhjspd`、Staging Supabase `ldivswlhtgmznzwhzsoi`。
- 原有 Staging 主用户名接口 `mmh-n10a6-username` 继续硬编码关闭；真实 Staging 用户名＋密码仍 NOT RUN。
- **禁止在这个原型中输入真实账号密码**。请只体验预设的 `demo_user`、`demo@example.invalid` 等无关示例。
